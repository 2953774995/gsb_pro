# sheet

`sheet` 是一个在终端里运行的迷你电子表格。它可以加载 CSV，在 REPL 中查看数据、设置公式，并通过依赖图自动重算，最后把计算结果重新导出为 CSV。

除运行测试需要 `pytest` 外，程序只使用 Python 标准库。

## 运行

```bash
# 进入交互界面
python3 -m sheet

# 启动时自动加载文件
python3 -m sheet data.csv

# 运行测试
pytest -q
```

## 地址和数据类型

- 列名：`A` 到 `Z`，之后是 `AA`、`AB`……
- 行号：从 1 开始。
- 单元格地址：`A1`、`B2`、`AA10`。
- 单元格内容：
  - 数字：`123`、`-4.5`、`1.08`
  - 文本：普通 CSV 字段，或 `set` 时直接输入的非公式文本
  - 公式：以 `=` 开头
- 空单元格作为普通引用时按 `0` 处理；在区域函数中，空单元格不参与 `COUNT/MIN/MAX/AVG` 的计数。

## 公式语法

公式由内置递归下降解析器解析，没有使用 `eval`。

### 1. 四则运算和括号

```text
=1+2*3
=(A1+B2)/2
=-5+C3
=10-2-3
```

运算符优先级：

1. 括号
2. 一元 `+`、`-`
3. `*`、`/`
4. `+`、`-`
5. `&`
6. 比较运算

同级运算从左到右结合。除以零会得到 `#DIV/0!`。

### 2. 单元格引用

```text
=A1+B2*2
=D12*1.08
```

### 3. 区域和函数

支持以下函数，参数可以是 `A1:A10` 这样的区域、普通表达式，或嵌套函数：

| 函数 | 含义 |
| --- | --- |
| `SUM` | 数值求和 |
| `AVG` / `AVERAGE` | 数值平均值 |
| `MIN` | 最小值 |
| `MAX` | 最大值 |
| `COUNT` | 数字单元格/数字表达式数量 |

示例：

```text
=SUM(A1:A10)
=AVG(B2:B20)
=SUM(A1:A5)+MAX(B1:B5)
=MIN(C1:C10)-MAX(D1:D10)
=COUNT(A1:C20)
```

区域可以是单列、单行或矩形区域，例如 `A1:A10`、`A1:F1`、`B2:D8`。起始地址大于结束地址时程序会自动归一化。

### 4. 比较运算

比较结果显示为 `TRUE` 或 `FALSE`：

```text
=A1>100
=B2<=10
=C3="完成"
=A1<>B1
```

支持：`=`、`<>`（也接受 `!=`）、`<`、`<=`、`>`、`>=`。

### 5. 字符串拼接

`&` 会把值转成显示文本后拼接，适合生成说明文字：

```text
="合计: "&B2
=A1&" / "&B2
```

字符串用双引号表示；字符串内部的双引号写成两个双引号：

```text
="他说""你好"""
```

### 6. 错误值

| 错误 | 含义 |
| --- | --- |
| `#DIV/0!` | 除以零，或对没有数字的区域求平均值 |
| `#CYCLE!` | 公式之间存在循环引用 |
| `#PARSE!` | 公式语法错误 |
| `#VALUE!` | 类型不匹配、错误使用区域等 |

错误会沿公式继续传播。例如 `=1/0+A1` 为 `#DIV/0!`，依赖它的公式也会显示该错误。

## 自动重算

每个公式保存了解析出的依赖：

- 改一个单元格时，只沿反向依赖图找出直接和间接依赖它的公式；
- 对受影响子图做拓扑排序，按依赖顺序求值；
- 如果子图包含循环，循环内及读取循环结果的公式显示 `#CYCLE!`；
- 不会每次全表扫描重算。

例如：

```text
A1 = 1
B1 =A1+1
C1 =B1+1
```

把 `A1` 改成 10 后，`B1` 和 `C1` 会分别自动变成 11、12。

## REPL 命令清单

| 命令 | 作用 |
| --- | --- |
| `load <file.csv>` | 加载 CSV，并替换当前表格 |
| `save <file.csv>` | 保存 CSV；公式写计算后的值 |
| `set <cell> <内容>` | 设置数字、文本或公式 |
| `show [A1:D10]` | 显示全表或指定区域 |
| `<单元格地址>` | 查看该单元格的内容/公式和计算值 |
| `clear <cell>` | 清空单元格 |
| `help` | 查看帮助 |
| `quit` / `exit` | 退出 |

示例：

```text
sheet> load sales.csv
sheet> set B2 =A1*1.08
sheet> set C2 ="合计: "&B2
sheet> show A1:D10
sheet> B2
sheet> save out.csv
sheet> quit
```

`set` 同时支持等号两侧带空格和不带空格：

```text
set B2 =A1*1.08
set B2=A1*1.08
set C1 普通文本
set A3 42
```

## show 的显示规则

- 第一行显示列字母，第一列显示行号。
- 数字和错误值右对齐；文本左对齐。
- 列宽根据显示内容自适应。
- 默认单元格最大显示宽度为 20 个字符；超宽内容会用 `…` 截断。
- 中文等宽字符按两个终端字符宽度计算。
- 单元格内嵌的换行符显示为 `⏎`，制表符显示为空格，不会破坏表格对齐。

## CSV 说明

- 读写使用标准库 `csv`。
- 支持带引号字段、字段内逗号、字段内换行和空行。
- 保存时公式单元格写计算后的值，不写公式本身。
- 空行会尽量保留；由逗号形成的尾部空字段也会保留。
