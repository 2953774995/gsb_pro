# sheet

`sheet` 是一个运行在终端里的迷你电子表格。它能加载 CSV、进入交互式命令行（REPL）、给单元格设置公式、按依赖关系自动重算，并把公式结果重新导出为 CSV。

- 只使用 Python 标准库（测试使用 `pytest`）
- 自己实现公式分词器、递归下降解析器和求值器，**没有使用 `eval`**
- 使用依赖图 + Kahn 拓扑排序做增量重算和循环引用检测
- 支持带引号、逗号和换行字段的 CSV

## 运行要求

- Python 3.10+
- 运行测试时需要 `pytest`

## 快速开始

```bash
./sheet-cli data.csv
# 或
python3 -m sheet data.csv
```

进入界面后：

```text
sheet> set B1 =A2*1.08
sheet> show A1:B5
sheet> B1
sheet> save out.csv
sheet> quit
```

也可以不带文件启动，然后在 REPL 中执行 `load data.csv`。

## 单元格和数据类型

- 列名：`A` 到 `Z`，之后是 `AA`、`AB`、...
- 行号：从 `1` 开始
- 地址示例：`A1`、`BC12`
- 普通内容：
  - `123`、`-3.5`、`1.08` 会识别为数字
  - `TRUE`、`FALSE` 会识别为布尔值
  - 其他内容按文本保存
- 公式以 `=` 开头，例如 `=A1+B2*2`
- 公式引用空单元格时，空单元格在算术中按 `0` 处理

整数结果没有小数时仍保留电子表格风格的一位小数展示，例如：

```text
100 * 1.08 => 108.0
```

## 公式语法

### 算术运算和括号

支持 `+`、`-`、`*`、`/` 和圆括号，也支持一元正负号：

```text
=1+2*3            => 7
=(1+2)*3          => 9
=A1+B2*2
=-A3+5
=--4
=8/2/2
```

优先级从高到低为：

1. 括号、数字、文本、单元格引用、函数调用
2. 一元 `+` / `-`
3. `*` / `/`
4. `+` / `-`
5. `&`
6. 比较运算

### 比较运算

支持：

| 运算 | 含义 |
| --- | --- |
| `=` | 等于 |
| `<>` | 不等于 |
| `<` | 小于 |
| `<=` | 小于等于 |
| `>` | 大于 |
| `>=` | 大于等于 |

比较结果显示为 `TRUE` 或 `FALSE`：

```text
=A1>100
=B2<>0
=A1>=B2
```

### 字符串拼接

用 `&` 拼接文本，双引号中的两个双引号表示一个引号：

```text
="合计: "&B2
="Hello, "&"world"
="say ""hi"""
```

### 区域引用和函数

区域写法为 `左上角:右下角`，如 `A1:A10`、`B2:D8`。支持跨多行多列的矩形区域、单行区域和单列区域。

| 函数 | 作用 |
| --- | --- |
| `SUM(range)` | 求和 |
| `AVG(range)` / `AVERAGE(range)` | 平均值 |
| `MIN(range)` | 最小值；空区域为 `0` |
| `MAX(range)` | 最大值；空区域为 `0` |
| `COUNT(range)` | 统计区域中的数字个数 |

示例：

```text
=SUM(A1:A10)
=AVG(B1:B5)
=MIN(C2:C20)
=MAX(B1:B5)
=COUNT(A1:C9)
=SUM(A1:A5)+MAX(B1:B5)
```

区域中的空单元格会被忽略；在普通算术里直接引用空格则按 `0` 计算。区域中的文本不会参与数值聚合。

### 错误值

| 显示 | 含义 |
| --- | --- |
| `#DIV/0!` | 除以零，或对没有数字的区域求平均 |
| `#VALUE!` | 值类型无法参与当前运算，或公式语法错误 |
| `#NAME?` | 未知函数名 |
| `#CYCLE!` | 检测到循环引用 |

错误会沿公式依赖继续传播。例如 `=1/0+A2` 和依赖它的公式都会显示相应错误。

## 循环引用与自动重算

内部维护两张图：

- `dependencies[cell]`：某个公式直接依赖哪些单元格
- `dependents[cell]`：修改某个单元格后，哪些公式直接依赖它

修改单元格时，只沿反向依赖图收集受影响的公式，然后在受影响子图上执行拓扑排序：

- 能完成拓扑排序的公式按顺序重算
- 留在环中的公式显示 `#CYCLE!`
- 依赖这些环的下游公式也显示 `#CYCLE!`
- 不会全表扫描，也不会因为环而死循环

例如：

```text
set A1 =B1+1
set B1 =A1+1
```

`A1` 和 `B1` 都显示 `#CYCLE!`。再执行 `set B1 10` 后，`A1` 会自动恢复为 `11`。

## REPL 命令清单

| 命令 | 说明 |
| --- | --- |
| `load data.csv` | 加载 CSV，并替换当前工作簿 |
| `save out.csv` | 保存 CSV；公式单元格写计算后的值 |
| `set A1 123` | 设置常量或文本 |
| `set B2 =A1*1.08` | 设置公式 |
| `show` | 显示整个表格 |
| `show A1:D10` | 显示指定区域 |
| `A1` | 查看某个单元格的公式和值 |
| `help` | 显示帮助 |
| `quit` / `exit` | 退出 |

`show` 输出规则：

- 列宽按内容自适应，默认最大列宽为 20 个显示列
- 数字右对齐，文本和错误左对齐
- 超过最大宽度的内容截断并加 `…`
- 同时考虑中文等宽字符的显示宽度
- 打印列字母和行号，便于继续输入地址

直接查看公式格：

```text
sheet> B2
公式: =A1*1.08  值: 108.0
```

## CSV 规则

使用 Python 标准库 `csv`：

- 支持带引号字段：`"Doe, Alice"`
- 支持字段中的逗号、换行和转义引号
- 真空行会保留为空行
- 只有逗号的行会保留为空字段
- 保存时公式不会以 `=...` 写出，而是写当前计算结果

示例：

```csv
name,note,amount
"Doe, Alice","line1
line2",10
Bob,"say ""hi""",20
```
